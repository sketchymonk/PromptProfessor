Palette

Never pure black. Never pure white. Gold is signature, reserved for accents + CTAs + signature moments. Semantic colors desaturated so they don't fight the gold.

Design rationale · what to evaluate

  • Luxe restraint. Marble/gilded/serif-display appear only at moments of weight (verdict stamps, boardroom headers, capstone reveal). Everyday chrome (nav, forms, lists) stays clean and professional. Overuse collapses the aesthetic into pastiche — flag anywhere this feels crossed.
  • Persona separation. Trump's voice saturates copy (empty states, errors, verdicts). The UI chrome around that copy is neutral so the platform reads as a real learning tool, not a rally. If we ever swap persona, only copy files change.
  • Color-as-meaning. Gold = brand/celebration. Forest-green = correct. Burgundy = incorrect/fired. Never bright red — it'd fight Trump's tie and collapse the luxe register. Also: color never carries information alone (all diffs have icons + labels).
  • Motion registers. Utility motion 150–250ms (hovers, state). Hero motion 400–700ms with overshoot (stamp land, Trump Version reveal, save-to-library). Weight conveys luxury. All disabled under prefers-reduced-motion.
  • Avatar = caricature. The placeholder SVG is deliberately abstract — a right-of-publicity hedge. Final art is a commissioned stylized cartoon caricature, not photo-real, not AI-generated from reference photos.
  • Port path. Every CSS custom property in tokens.css maps 1:1 to a future tailwind.config.ts entry. This spike doesn't throw away work — it locks the tokens.
